  - `colors.textMuted`: Muted text (website URL)
  - `texts.introHook`: Introduction hook text
  - `texts.introSub`: Introduction sub-text
  - `texts.offerBadge`: Offer badge text
  - `texts.offerAmount`: Offer amount text
  - `texts.offerDesc`: Offer description
  - `texts.ctaUrgency`: Call-to-action urgency text
  - `texts.ctaButton`: Call-to-action button text
  - `texts.ctaWebsite`: Call-to-action website URL
  - `fonts.family`: Font family
